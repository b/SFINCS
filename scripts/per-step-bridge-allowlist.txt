# scripts/per-step-bridge-allowlist.txt — SOR-69 Phase 5
#
# Allowlist for scripts/check-no-per-step-bridges.sh. Each non-comment
# line is `<file>:<line>:<exact trimmed line text>` and exempts that
# specific call site from the canonical-on-device regression guard.
#
# Every entry is one of:
#   (1) a gated feature-boundary bridge that fires only when its
#       feature predicate is true (e.g. `if (use_qext_h) call
#       bridge_in_cell_real4(qext, qext_h)`); the inner-loop fast
#       path bypasses it on validation cases that leave the feature
#       off, and the bridge IS the feature-boundary refresh when
#       the feature is on, OR
#   (2) an output-reset-cycle bridge that synchronizes a host array
#       with the device after the host has been mutated by the
#       per-output-interval reset in sfincs_output.f90 (vmax / qmax /
#       twet) -- the reset cycle has no on-device equivalent yet, so
#       the bridge stands as the propagation path.
#
# Adding new entries requires (a) reviewing the canonical-on-device
# invariant in docs/gpu_canonical_on_device.md, (b) explaining in the
# PR description why the bridge cannot be moved to a feature-boundary
# entry point (sfincs_partition.cuf flush/pull helpers) or to an
# output-cadence flush (device_to_host_for_output), and (c) capturing
# the per-step PCIe impact in a NSight delta vs the SOR-69 Phase-5
# profile so the operator can quantify any regression.
#
# Updating line numbers: line numbers shift as the files evolve. The
# guard does an exact-match on `file:line:line-text` so any edit that
# moves a bridge MUST update both the line number AND the text. A
# silent rewrite that leaves the allowlist key stale will fail the
# guard.

# ---- momentum_gpu.cuf -------------------------------------------------
# compute_fluxes copy-IN: gated on `if (nonhydrostatic_h)`. When NH is
# enabled, sfincs_nonhydrostatic.f90 writes uv on the host between
# compute_fluxes calls; the H2D bridge re-publishes that host write to
# the device before the next compute_fluxes reads it. The bridge is a
# no-op when NH is off, which is every case in the validation matrix
# (no validation case enables nonhydrostatic). Phase 4's
# pull_host_state_to_device_nonhydrostatic helper covers the wider
# nonhydrostatic state surface; this in-loop bridge is the narrow
# uv-only refresh paired with the NH host write.
source/src/sfincs_momentum_gpu.cuf:146:call bridge_in_edge_real4(uv, uv_h)
# compute_fluxes copy-OUT: gated on `if (timestep_analysis_h)`. The
# per-uv kernel writes timestep_analysis_required_timestep on device;
# the host-side timestep_analysis_update consumer reads its host alias
# every step. Bridge fires only when timestepanalysis=1 (off in every
# validation case and in case_prod_compound_snapwave).
source/src/sfincs_momentum_gpu.cuf:222:call bridge_out_edge_real4(timestep_analysis_required_timestep_h, timestep_analysis_required_timestep)
